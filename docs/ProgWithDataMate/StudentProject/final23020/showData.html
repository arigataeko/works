世界の1日のインターネットの利用時間

DATAREPORTALは、世界のインターネットの利用時間の平均を毎年 Global Overview Reportにて公開しています。
これはGlobal Overview Reportの2020年版から2024年版の4年分のデータをもとに、世界の16歳から64歳までの
インターネット利用者があらゆるデバイスでインターネットを利用する国別の平均時間を集計したデータです。

Global Overview Report2020からGlobal Overview Report2024まで連続して掲載されていた40カ国のデータを視覚化しました。
